# Prompt 评测工作台 PRD

## 背景

当前模板页的 Prompt 评测通过 `POST /api/templates/:id/evaluate` 同步执行。一次完整评测包含原版样例评测、AI 生成优化版 Prompt、优化版样例评测和指标对比，默认需要多次模型调用。长请求容易出现浏览器等待时间过长、代理超时、用户无法判断进度的问题。

## 目标

将 Prompt 评测升级为可视化后台任务体验：

- 点击评测后立即创建任务并返回 `jobId`。
- 前端展示阶段进度、实时日志、耗时、取消入口和最终报告。
- 后端通过 SSE 推送任务状态，避免长 HTTP 请求阻塞。
- 保留原同步评测接口，降低兼容风险。

## 用户故事

- 作为模板维护者，我点击「评测」后能马上看到任务已经开始，而不是等待空白弹窗。
- 作为测试架构师，我能看到当前卡在哪个阶段，例如原版样例、AI 优化、优化版样例或指标对比。
- 作为管理员，我能在评测耗时过长时取消任务。
- 作为模板作者，我能在任务完成后查看原版/优化版对比和完整优化版 Prompt 草稿。

## 功能范围

### 本期包含

1. 创建后台评测任务。
2. 查询评测任务状态。
3. SSE 推送评测进度。
4. 取消待执行或阶段间可中止任务。
5. 模板页评测弹窗升级为「评测工作台」。
6. 完成后展示已有评测报告结构。
7. 生产 Nginx 增加评测 SSE 专用代理配置。

### 本期不包含

1. 不持久化任务到数据库。
2. 不做跨进程/重启恢复。
3. 不做一键保存优化版 Prompt。
4. 不引入 BullMQ 或 Redis 队列。

## 评测阶段

| 阶段 | 说明 |
| --- | --- |
| queued | 任务创建完成，等待后台执行 |
| format_check | Prompt 格式体检 |
| original_evaluation | 原版 Prompt 样例评测 |
| ai_optimization | AI 生成优化版 Prompt |
| guardrail_check | 优化版 Prompt 守护校验 |
| optimized_evaluation | 优化版 Prompt 样例评测 |
| comparison | 原版/优化版指标对比 |
| completed | 任务完成 |
| failed | 任务失败 |
| cancelled | 用户取消 |

## 成功指标

- 用户点击评测后 1 秒内看到任务面板。
- 任务运行中至少每 1 秒可看到状态心跳或阶段更新。
- 普通代理超时不再影响评测任务本身。
- 旧同步评测接口继续可用。

## 交互要求

- 评测工作台沿用模板页深色卡片、细边框、青色/蓝色强调色。
- 阶段进度使用时间线，不做营销式 hero 或大面积装饰。
- 完成后显示指标对比、风险建议、AI 优化建议和完整 Prompt 草稿。
- 失败时显示失败阶段和错误原因。
- 取消后显示已取消，不展示误导性完成报告。
