# 截图资产

该目录用于保存 README 和评估报告引用的真实产品截图。

建议按以下命名维护：

- `ai-analysis-runtime.png`：AI 需求分析页，展示上传、解析进度、评分、REQ/TP 信息。
- `review-coverage-matrix.png`：评审中心覆盖矩阵。
- `settings-runtime-queues.png`：设置页运行环境，展示 Redis、队列和 Worker 状态。
- `generate-case-pagination.png`：生成用例页分页与渲染状态。

截图要求：

- 使用 develop 或 main 的真实页面，不放设计稿或伪造图片。
- 隐藏账号、Token、API Key、数据库地址等敏感信息。
- 宽屏截图建议使用 1440px 或 1600px 宽度，移动端截图建议保留设备边界。
